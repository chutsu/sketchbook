# sketchbook

A personal sketchbook of notes, scripts, and small implementations --
mostly robotics, computer vision, and machine learning.

## Layout

- `src/` - Python notes and small implementations.
- `leet/` - LeetCode-style problems and algorithm notes.
- `opengl/` - Standalone OpenGL/GLFW rendering module.
- `docs/` - Notes rendered as a static site.
- `scripts/` - Misc utility and setup scripts.
- `archive/` - Older, unmaintained experiments.
- `data/` - Datasets used by the notes/scripts (MNIST, Stanford bunny).

## Setup

```
make env   # create a venv and install requirements.txt
```

## Docs

```
make docs  # prints how to serve docs/index.html locally
```
